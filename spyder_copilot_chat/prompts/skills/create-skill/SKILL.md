Related skill: `agent-customization`.

Guide the user to create a `SKILL.md`.

## Extract from Conversation
Review the conversation history. If the user has been following a multi-step workflow or methodology, generalize that into a reusable skill. Extract:
- The step-by-step process being followed
- Decision points and branching logic
- Quality criteria or completion checks

## Clarify if Needed
- What outcome should this skill produce?
- Workspace-scoped or personal?
- Quick checklist or full multi-step workflow?

## Iterate
1. Draft the skill and save it
2. Identify ambiguous parts and clarify
3. Summarize, suggest example prompts, and propose related customizations
