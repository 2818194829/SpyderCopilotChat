# How to setup a project using context7 tools

Use context7 tools to find the latest libraries, APIs, and documentation to help create and customize projects.

1. Call the `mcp_context7_resolve-library-id` tool with project requirements
2. Call the `mcp_context7_get-library-docs` tool to get scaffolding instructions
